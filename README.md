# ✨ Animated Portfolio Website

A modern, responsive, and interactive portfolio website designed to showcase my skills, projects, and experience as a developer. Featuring smooth animations, clean UI, and an engaging user experience.

## 🚀 Features

- 🎨 Modern and clean user interface
- 📱 Fully responsive design
- ✨ Smooth animations and transitions
- 👨‍💻 About Me section
- 🛠️ Technical skills showcase
- 📂 Projects portfolio
- 📬 Contact section
- ⚡ Optimized performance and user experience

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Version Control:** Git & GitHub
